1. 系统概览

BossBar 系统是一个完全替换原版Boss血条的自定义渲染框架。它接管了 Terraria 的 IBigProgressBar 绘制机制，提供渐变色、彩虹色、故障特效、抖动特效、粒子效果和条件配置切换等丰富的视觉效果。

🎯 设计目标

  • 替換原版单调的Boss血条
  • 每个Boss拥有独特的视觉效果
  • 支持多Boss同时显示（最多4条）
  • 支持模组Boss（Fargo's Souls, Fargo's Crossmod）

2. 生命周期与入口

2.1 BossBarSystem.cs — 系统总入口 ModSystem

生命周期方法职责
PostSetupContent() 初始化整个BossBar系统的唯一入口。按顺序执行：
① 实例化 BossComboGlobalNPC
② BossBarRegistry.Initialize() — 创建配置字典
③ BossBarParticleSystem.Initialize() — 创建粒子字典
④ ShieldDetector.InitializeReflection() — 反射获取原版盾字段
⑤ BossBarRegistry.RegisterAllBossBars() — 注册所有Boss
PostUpdateNPCs() 每帧调用。每 60 帧 更新一次天柱系统，每 300 帧 清理一次过期数据（死亡NPC的Combo数据、孤儿阶段数据、非活跃NPC的粒子）
Unload() 释放所有静态资源：清空注册表、粒子系统、天柱进度、Combo数据、EntityShieldHelper

还提供静态 API：RegisterBossBar()、HasCustomBossBar()、GetSystemInfo()、PrintDebugInfo()

2.2 CustomBossBarStyle.cs — 替换原版血条 ModBossBarStyle

设置 PreventDraw = true 禁用原版渲染，完全接管血条绘制。

CustomBossBarStyle.Draw() ├─ HasMultipleBosses() ? │ ├─ YES → DrawMultipleBossBars() 迭代 MultiBossBarSystem.GetActiveBosses() │ └─ NO → DrawSingleBossBar() 通过 EnemyDetector 查找目标 │ └─ 两种路径最终都调用： BossBarRenderer.DrawCustomBossBar() 或 DrawCustomBossBarAt()

3. 配置系统

3.1 BossBarConfig.cs — 核心配置POCO

定义单个Boss血条的完整外观和行为，包含 40+ 个属性：

分组属性说明
基础 BarColor, HealthBarTexture, ShieldBarTexture, BackgroundTexture 颜色、纹理路径
反射 UseReflection, TargetMod, TargetNPCName 用于从模组NPC读取自定义血量字段
彩虹模式 UseRainbow, RainbowSpeed, RainbowWaveLength, RainbowReverse, RainbowMode, RainbowIntensity HSL色相环扫描效果（4种模式）
自定义渐变 UseCustomGradient, GradientColors[], GradientSpeed, GradientReverse, GradientMode, GradientIntensity, GradientSmooth 颜色数组插值（8种模式）
垂直条带 VerticalBandCount, VerticalBandSmooth, VerticalBandOffset VerticalSweep/Wave模式参数
特效 SpecialEffect, GlitchFrequency, GlitchDuration, GlitchIntensity, ShakeIntensity, ShakeDuration, ShakeDecay, GlitchVisual 故障脉冲 / 宇宙抖动 / 两者混合
粒子 ParticleEffect, ParticleStyle, ParticleColor, ParticleColor2, ParticleColor3, ParticleCount, ParticleSpeed, ParticleScale, ParticleTexture, ParticleUseRainbow 血条周围粒子效果
名称 DisableNameEffects 禁用Boss名称文字特效

3.2 GetActiveConfig() — 条件配置动态覆盖

当 ConditionalParams 不为空且条件函数返回 true 时，创建一个新的 BossBarConfig 副本并用条件参数逐字段覆盖，实现同一Boss在不同条件下的视觉切换（如光之女皇白天/黑夜切换彩虹→渐变配色）。

3.3 ConditionalParameters.cs — 条件参数容器

包含一个 Func<bool> Condition 委托和所有可覆盖的 Nullable<T> 字段，完全镜像 BossBarConfig 的属性集。

6. 粒子系统

6.1 BossBarParticle.cs — 粒子数据类

属性说明
Position, Velocity位置和速度向量
Color, Scale, Rotation外观属性
TimeLeft, MaxTime生命周期（Alpha = TimeLeft/MaxTime）
SpiralAngle, SpiralRadius, SpiralSpeed, SpiralCenter螺旋模式专属参数
FallSwayOffset下落摇摆偏移

3种运动模式（Update() 方法）：

  1. 螺旋模式 — 粒子围绕动态中心点旋转，螺旋半径随时间变化
  2. 下落模式 — 粒子下落，X轴呈正弦波摇摆
  3. 标准模式 — 线性速度 + 旋转

6.2 BossBarParticleSystem.cs — 粒子系统管理器

维护 Dictionary<int, List<BossBarParticle>> 按NPC索引存储粒子。

  • 使用 Stopwatch 计算 deltaTime，实现帧率无关更新
  • 每 3帧 生成一次粒子，达到 ParticleCount 上限后停止
  • 死亡/消失NPC的粒子在 CleanupInactiveNPCs() 中清理

7. 特效系统

7.1 BossBarEffectTracker.cs — 特效状态机 ModSystem

维护每个NPC的故障状态和抖动状态：

  • GlitchState — 定时开关故障效果（频率/持续时间/强度）
  • ShakeState — 抖动幅度衰减（受击时触发，最大3倍强度）
  • 在 PostUpdateNPCs 中更新计时、清理死亡NPC的状态

7.2 BossBarEffectGlobalNPC.cs — 受击事件触发 GlobalNPC

  • OnHitByItem / OnHitByProjectile — 检测Boss是否配置了 CosmicShake 或 GlitchAndShake，若配置则调用 TriggerShake()
  • OnKill — 清理该NPC的粒子数据

8. 盾牌检测系统

8.1 ShieldDetector.cs — 原版盾牌检测

通过反射读取 NPC.shieldStrength / NPC.maxShieldStrength 字段。

四柱 (Celestial Pillars)

  • Solar(517) / Nebula(507) / Stardust(493) / Vortex(422)
  • 盾牌进度 = 击杀对应敌怪数 / 所需击杀数
  • 所需击杀数：月前100只 / 月后50只
  • 每个天柱有硬编码的敌怪类型HashSet
  • 线程安全的击杀注册（lock）

克苏鲁之脑 (Brain of Cthulhu, NPC 266)

  • 盾牌进度 = 存活飞眼怪数 / 难度决定的总数（普通20/专家30/大师40）

8.2 EntityShieldHelper.cs — 通用实体盾框架

可扩展的盾牌注册系统，支持三种进度计算模式：

  • TotalHealth — 所有盾实体生命值总和 / 最大生命值总和
  • EntityCount — 存活实体数 / 缓存最大数（30帧刷新）
  • Custom — 自定义进度函数

当前无活跃注册（之前为 HypnosBoss 和 PyrogenBoss 注册的已被移除），框架保留供未来扩展。

9. Combo伤害覆盖系统

BossComboGlobalNPC.cs — 伤害连击可视化 GlobalNPC

当一个Boss受击时，记录受击前的血量百分比作为覆盖的起点。在血条上渲染一个从旧血量缓慢衰减到新血量的彩色/渐变色覆盖层。

核心状态字典（每个Boss索引一份）

字典类型说明
_damageOverlayPercentDictionary<int, float>当前覆盖血量百分比
_fadeDelayTimerDictionary<int, int>60帧延迟后开始衰减
_pulseTimerDictionary<int, float>脉冲动画计时器（速度0.08/tick）
_glowActiveDictionary<int, bool>发光激活（sin(pulse) ≥ 0.9）

特殊处理

  • 多节Boss (Eater of Worlds 13/14/15) — 使用虚拟索引聚合所有节段的血量
  • 衰减速率 — 0.1f/tick（约每秒6次更新）
  • LRU驱逐 — 最多追踪200个NPC，超出时清理最早的
  • 脉冲 — 当覆盖差大于1%时激活，正弦波1.0~1.15倍缩放
